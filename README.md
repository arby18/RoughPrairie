# RoughPrairie

Translates raw cryptocurrency transaction data into easy-to-read charts and graphs for traders and analysts.

RoughPrairie is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- Translates raw cryptocurrency transaction data
- into easy-to-read charts and graphs
- for traders and analysts

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/RoughPrairie.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
